# Аналитика каталога стримингового сервиса

Учебный uv-проект на Python 3.12 или новее. Каталог и функции всех девяти
этапов находятся в `catalog_analysis.py`.

## Запуск

Установите uv, затем в каталоге проекта выполните:

```bash
uv sync --locked
uv run catalog_analysis.py
uv run ruff check .
```

При первом запуске uv создаёт `.venv` и устанавливает зависимости из `uv.lock`.
Единственная сторонняя зависимость проекта — Ruff для проверки стиля.

## Итоговый отчёт

Вызов `build_report(movies)` в блоке `if __name__ == "__main__":` выводит средний
рейтинг, средний возраст фильмов, топ-3, количество фильмов по жанрам и список
уникальных жанров. Импорт модуля не печатает отчёт. Возраст по умолчанию
рассчитывается на 2026 год.

Упражнения с `continue`, `while` / `break` / `else`, генератором словаря
и генераторным выражением сохранены в отдельных функциях
`print_non_comedy_titles`, `print_first_masterpiece`, `ratings_above_average`,
`print_high_rated_movies` и `total_duration_above_seven`.

В репозитории сохраняются `pyproject.toml` и `uv.lock`.
Виртуальное окружение `.venv` и кэш проверок не включаются.
